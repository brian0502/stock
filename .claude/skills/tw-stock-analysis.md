# Taiwan Stock Analysis Skill

## Skill Name
tw-stock-analysis

## Description
分析台股持股，提供買進、賣出或加碼建議。

## Instructions

當使用者要求分析台股時，請按照以下步驟操作：

### 1. 取得持股資訊
- 詢問使用者目前持有的台股標的（股票代號與名稱）、持有張數/股數、以及買入均價
- 如果使用者已在對話中提供，則直接使用
- 如果專案中有 `tw_portfolio.json` 或 `tw_portfolio.csv` 檔案，則讀取該檔案取得持股資訊
- 台股代號格式為純數字（如 2330、0050）

### 2. 查詢即時市場資訊
使用 WebSearch 工具查詢以下資訊：
- 每檔股票的**當前股價**（搜尋：`{股票代號} {公司名稱} 股價`）
- **近期新聞與事件**（搜尋：`{股票代號} {公司名稱} 最新新聞`）
- **財報數據**（搜尋：`{股票代號} {公司名稱} 營收 EPS 季報`）
- **分析師評級與目標價**（搜尋：`{股票代號} {公司名稱} 目標價 法人評等`）
- **技術面指標**（搜尋：`{股票代號} {公司名稱} 技術分析 KD RSI 均線`）
- **法人買賣超**（搜尋：`{股票代號} 三大法人買賣超`）

### 3. 分析框架
對每檔股票進行以下分析：

#### 基本面分析
- 本益比 (P/E Ratio)
- 每股盈餘 (EPS) 與成長趨勢
- 營收月增率 / 年增率
- 毛利率 / 淨利率趨勢
- 股息殖利率與配息穩定度
- 負債比率
- 股價淨值比 (P/B Ratio)

#### 技術面分析
- 目前股價相對於 5 日 / 20 日 / 60 日 / 240 日均線的位置
- KD 指標（K 值與 D 值交叉）
- RSI 指標（超買 >80 / 超賣 <20）
- MACD 指標趨勢
- 近期成交量變化
- 支撐位與壓力位

#### 籌碼面分析
- 三大法人（外資、投信、自營商）近期買賣超
- 融資融券變化
- 大戶持股比例變化
- 主力進出動向

#### 市場情緒分析
- 法人研究報告共識
- 產業趨勢與政策利多/利空
- 近期重大新聞影響

### 4. 產出投資建議

針對每檔股票，給出以下格式的建議：

```
## {股票代號} - {公司名稱}

### 當前狀態
- 現價: NT$XXX
- 持有成本: NT$XXX
- 持有股數: XXX 股（X 張）
- 未實現損益: +/- NT$XXX (XX.X%)

### 分析摘要

**基本面**: (簡述)
**技術面**: (簡述)
**籌碼面**: (簡述)
**市場情緒**: (簡述)

### 建議操作: 🟢 買進 / 🔴 賣出 / 🟡 持有 / 🔵 加碼

**建議理由**: (詳細說明)

**風險提示**: (潛在風險)

**目標價位**:
- 短期目標 (1-3個月): NT$XXX
- 中期目標 (3-6個月): NT$XXX
- 停損價位: NT$XXX
```

### 5. 投資組合總結

在分析完所有個股後，提供整體投資組合建議：
- 總市值與損益（以新台幣計算）
- 產業分布是否均衡
- 風險集中度評估
- ETF 與個股配置比例
- 整體調整建議

### 6. 免責聲明
每次分析結束時，務必附上以下免責聲明：

> **免責聲明**: 以上分析僅供參考，不構成投資建議。股票投資有風險，過去的表現不代表未來的結果。請根據自身風險承受能力做出投資決定，並考慮諮詢專業的財務顧問。

## User Invocation
- 使用者可以透過 `/tw-stock-analysis` 來觸發此 skill
- 也可以直接說「分析我的台股」、「幫我看一下台股」等自然語言觸發

## Tools Used
- WebSearch: 查詢即時股價、新聞、財報數據、法人買賣超
- WebFetch: 取得詳細的分析報告頁面
- Read: 讀取本地的持股檔案 (tw_portfolio.json / tw_portfolio.csv)
- Write: 將分析結果儲存為報告檔案
