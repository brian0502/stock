# Stock Analysis Skill

## Skill Name
stock-analysis

## Description
分析美股持股，提供買進、賣出或加碼建議。

## Instructions

當使用者要求分析股票時，請按照以下步驟操作：

### 1. 取得持股資訊
- 詢問使用者目前持有的美股標的（股票代號）、持有股數、以及買入均價
- 如果使用者已在對話中提供，則直接使用
- 如果專案中有 `portfolio.json` 或 `portfolio.csv` 檔案，則讀取該檔案取得持股資訊

### 2. 查詢即時市場資訊
使用 WebSearch 工具查詢以下資訊：
- 每檔股票的**當前股價**（搜尋：`{股票代號} stock price today`）
- **近期新聞與事件**（搜尋：`{股票代號} latest news`）
- **財報數據**（搜尋：`{股票代號} earnings revenue quarterly results`）
- **分析師評級與目標價**（搜尋：`{股票代號} analyst rating price target`）
- **技術面指標**（搜尋：`{股票代號} technical analysis RSI moving average`）

### 3. 分析框架
對每檔股票進行以下分析：

#### 基本面分析
- 本益比 (P/E Ratio)
- 營收成長率
- 毛利率 / 淨利率趨勢
- 自由現金流
- 負債比率

#### 技術面分析
- 目前股價相對於 50 日 / 200 日均線的位置
- RSI 指標（超買 >70 / 超賣 <30）
- 近期成交量變化
- 支撐位與壓力位

#### 市場情緒分析
- 分析師共識評級（買入/持有/賣出的比例）
- 機構持股變化
- 近期重大新聞影響

### 4. 產出投資建議

針對每檔股票，給出以下格式的建議：

```
## {股票代號} - {公司名稱}

### 當前狀態
- 現價: $XXX.XX
- 持有成本: $XXX.XX
- 持有股數: XXX
- 未實現損益: +/- $XXX.XX (XX.X%)

### 分析摘要

**基本面**: (簡述)
**技術面**: (簡述)
**市場情緒**: (簡述)

### 建議操作: 🟢 買進 / 🔴 賣出 / 🟡 持有 / 🔵 加碼

**建議理由**: (詳細說明)

**風險提示**: (潛在風險)

**目標價位**:
- 短期目標 (1-3個月): $XXX
- 中期目標 (3-6個月): $XXX
- 停損價位: $XXX
```

### 5. 投資組合總結

在分析完所有個股後，提供整體投資組合建議：
- 總市值與損益
- 產業分布是否均衡
- 風險集中度評估
- 整體調整建議

### 6. 免責聲明
每次分析結束時，務必附上以下免責聲明：

> **免責聲明**: 以上分析僅供參考，不構成投資建議。股票投資有風險，過去的表現不代表未來的結果。請根據自身風險承受能力做出投資決定，並考慮諮詢專業的財務顧問。

## User Invocation
- 使用者可以透過 `/stock-analysis` 來觸發此 skill
- 也可以直接說「分析我的持股」、「幫我看一下股票」等自然語言觸發

## Tools Used
- WebSearch: 查詢即時股價、新聞、財報數據
- WebFetch: 取得詳細的分析報告頁面
- Read: 讀取本地的持股檔案 (portfolio.json / portfolio.csv)
- Write: 將分析結果儲存為報告檔案
