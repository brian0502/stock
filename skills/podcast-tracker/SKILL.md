# 股癌 Podcast 追蹤工作流程

## 🎯 觸發時機

每次用戶請求「分析」、「美股分析」、「台股分析」、「組合分析」、「加碼建議」時，都應在分析前自動執行此工作流程。

## 📋 執行步驟（依序）

### Step 1：檢查已讀集數

**先讀取** `skills/podcast-tracker/episodes-read.md`

該檔記錄：
- 已分析過的集數（EP648-EP657 等）
- 各集主要主題、產業族群、提及個股
- 上次更新日期

**重要**：已讀集數**不需要再 fetch**，直接從檔案讀取摘要。

### Step 2：搜尋是否有更新的集數

只有當：
- 距離已讀最新集數已過 **3 天以上**
- 或用戶直接問「股癌最新一集」、「股癌有沒有提到 X」

才執行 web_search：
```
"股癌 EP[最新已讀+1] OR EP[最新已讀+2]" 重點 筆記
```

如果搜尋結果顯示沒有更新集數，**直接告訴用戶「目前最新已讀為 EP[N]，無新集數」**，不要做更多搜尋。

### Step 3：提取結構化資訊

對每個未讀新集數，提取：

```yaml
episode: EP[N]
date: YYYY-MM-DD
core_topic: [一句話主題]
sectors_mentioned:
  - 名稱: [族群名]
    觀點: [看多/看空/中性]
    理由: [簡述]
stocks_mentioned:
  - 代號: [台股 4 碼或美股 ticker]
    觀點: [買進/減碼/觀察/警告]
    理由: [簡述]
key_warnings:
  - [警告事項]
key_principles:
  - [心法/原則]
```

### Step 4：交叉比對用戶持倉

**用戶當前持倉**（每次分析確認）：
- 美股：NVDA、AMZN、MSFT、VOO、QQQ、INTC（投機）
- 台股：00878、00919、大魯閣

**交叉比對邏輯**：
- 若新集數提到用戶持倉 → **明確標示**並引述觀點
- 若提到用戶**曾考慮的標的**（台積電、聯發科、奇鋐等）→ 標示為「決策參考」
- 若提到全新族群 → 進入 Step 5

### Step 5：新族群挖掘（升級版 2026-05-20）

當股癌提到一個用戶尚未持有的族群時，**必須主動執行**：

#### 5.1 列出 3-5 檔具體標的

不只給「族群名」，要給**可執行的具體股票**：

1. **族群定義**：包含哪些子題材
2. **代表性股票**（3-5 檔）：含台股代號 + 簡介
3. **關鍵指標**：營收成長、本益比、近期股價區間
4. **進場建議**：合理價位、風險點、停損停利

#### 5.2 區分「龍頭已飆漲」vs「補漲低基期」

⚠️ **這是 2026-05-20 用戶教訓**：

不能只推龍頭股（往往已飆漲），要主動找「**還沒漲的補漲股**」：

```
被動元件族群（EP661+662）
├─ 🚫 龍頭已飆漲（不該新進場）：
│   └─ 國巨 2327 - 5/14 漲停 $462（從低點 +400%）
├─ 🟢 低基期補漲（可考慮）：
│   ├─ 信昌電 6173 - $83.2（5/28 +7.49%）
│   ├─ 凱美 2375 - $88.3
│   └─ 華新科 2492 - $220（4 月 EPS +454%）
└─ ⚠️ 已處置（流動性風險）：
    └─ 禾伸堂 3026（今年漲 +250%）
```

#### 5.3 連結到 market-opportunity-scan SKILL

提取股癌族群後，**呼叫 market-opportunity-scan SKILL** 做完整評估：
- 評分（1-5 星）
- 進場價建議
- 對比加碼現有部位

範例：股癌提到「被動元件」族群：
```
被動元件族群（EP661, EP662）
├─ 直接受惠：Intel (INTC)、AMD
├─ 台廠相關：祥碩 (5269)、技嘉 (2376)、華碩 (2357)
├─ 上游：聯發科 (2454)、世芯-KY (3661)
├─ 關鍵：缺貨持續度、Edge AI 真實滲透率
├─ 🔥 低基期補漲（推薦）：信昌電 6173 ⭐⭐⭐⭐
└─ 進場條件：等回檔 5-10% 後分批
```

### Step 6：給出整合建議

依股癌觀點 + 用戶紀律給出建議，**永遠保持中立**：

格式：
```
🎯 股癌 EP[N] 對你的影響

你的持倉中：
- [標的]：股癌觀點 [...]，建議 [動作]
- [標的]：論點不變，繼續持有

新族群機會：
- [族群名]：[標的列表]，等待 [進場條件]

⚠️ 警告：
- 股癌自己 EPxxx 警告過 [...]
- 不要超譯，獨立判斷
```

### Step 7：更新已讀記錄

將新分析過的集數寫入 `episodes-read.md`，避免下次重複處理。

### 絕對不能做的事

- ❌ 為了凑長度重複 fetch 已讀集數
- ❌ 鼓勵用戶完全照股癌做（操作邏輯不同）
- ❌ 把單一推測當已驗證事實（如 Intel 90% 良率）

## 📊 已知股癌操作模式

從 EP648-657 觀察到的模式：
1. **減碼中小型股 → 加碼大型權值股**（EP656）
2. **不預設高點，創高反而是介入點**（EP652）
3. **越跌越賣是阿呆谷**（EP648）
4. **猜對方向沒部位也賺不到錢**（EP650）
5. **小作文警告**（EP656：CPU/GPU 1:1 之說是炒作）

## 💡 與用戶決策的對應原則

| 用戶傾向 | 股癌觀點 | 建議 |
|---------|---------|------|
| 等回檔再買 | 創高就是買進時機（EP652）| 給用戶看雙方論點，最終尊重用戶紀律 |

| 投機追熱題 | 不要追小作文（EP656）| 警示風險 |
