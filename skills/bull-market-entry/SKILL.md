## 🎯 核心錯誤分析

### 錯誤 1：把「不追高」極端化成「永遠不進場」

- 「等回檔」在強多頭中等不到
- 5/19-5/20 真的有回檔（-716 點 + 跌破月線）時，Claude 還是叫「等」
- 等到回檔來了還在等 = 教條主義，不是紀律

### 錯誤 2：限價單設定是「假動作」

- 設「台積電 $2,220」當現價 $2,240（拉回僅 1%）
- 多頭中這種限價永遠不成交
- 只是製造「有在做事」的錯覺，實際讓用戶空手

### 錯誤 3：混淆「核心持倉紀律」與「建倉節奏」

| 概念 | 適用對象 | 正確做法 |
|------|---------|---------|
| **賣出紀律**（v3.1/停利/停損）| 已建立的核心部位 | 嚴格執行 |
| **建倉節奏**（本 SKILL）| 還沒建立的新部位 | 分批進場，不擇時 |

**長期持有 3-5 年的紀律,適用於「已建立部位」,不該拿來當「永不進場」的藉口。**

## 📋 多頭建倉正確框架

### 原則：不擇時，分批進場

| 舊錯誤做法 | 修正做法 |
|----------|---------|
| 等回檔限價（永不成交）| 分批進場（3-4 批）|
| 一次想買在最低點 | 先進 1/3，跌了再加 |
| 「過熱不能買」→ 歸零 | 過熱只降低單次金額，不歸零 |

### 標準分批節奏（總部位拆 3 批）

```
第 1 批（現在）：1/3 部位 — 市價或貼近市價，確保成交
第 2 批（回檔 -3~5%）：1/3 部位 — 限價單等拉回
第 3 批（回檔 -8~10% 或突破再進）：1/3 部位 — 視情況
```

**關鍵：第 1 批一定要進得去。多頭中「參與」比「買在最低」重要。**

### 過熱時的調整（不是歸零，是降額）

| 大盤狀態 | 第 1 批金額 |
|---------|-----------|
| 正常 | 總部位 1/3 |
| 短線過熱（連漲 +5%）| 總部位 1/5（降額但仍進場）|
| 極度過熱（連漲 +10%）| 總部位 1/10（小量參與）|

**永遠不要因為「過熱」就完全空手——那是上次的錯誤。**

## 🚦 何時可以「等」、何時該「進」

### 可以等的情況（真有理由）
- 個股本益比明顯過高（如群創 89 倍 EPS 僅 0.5）
- 投機炒作股、無基本面支撐
- 用戶要 all-in 單一標的（集中度風險）

### 必須進的情況（別再等）
- 強多頭趨勢確立 + 有基本面支撐的標的
- 用戶已多次表達想進場
- 大盤回檔已發生（如跌破月線）卻還在等
- ETF / 大盤型標的（分散風險，本就該定期進）

## 🔄 補充原則(2026-05-26):紀律要「動態調整」,不是「死守」

### 用戶 2026-05-26 提醒

> 「記得不要死守紀律,要動態調整」

### 為什麼這個提醒重要?

我(Claude)有一個失敗模式:**把紀律當成「固定數字」機械式套用**,而不是隨市場狀態調整。例如:
- 多頭中還死守「等回檔 -10%」→ 永遠空手(5/21-5/25 的錯誤)
- 數字寫死的限價單(如「拉回 1%」)→ 變成假動作
- 把「核心持倉賣出紀律」硬套到「建倉節奏」→ 混淆

### 「死守紀律」vs「動態紀律」的差別

| 死守紀律(錯)| 動態紀律(對)|
|------------|------------|
| 數字寫死,不管市場 | 隨多空、波動、趨勢調整 |
| 「等回檔 -10%」一條規則用到底 | 強多頭降低回檔期待、弱勢提高警戒 |
| 機械套用停利停損點 | 隨 ATH、波動率動態調整(已有 v3 trailing)|
| 規則 > 判斷 | 規則是框架,判斷是核心 |

### 動態調整的觸發情境(該檢討紀律參數時)

1. **趨勢轉變**:盤整→強多頭→空頭,回檔期待要跟著變
2. **波動率改變**:VIX 飆高時,停損緩衝要放寬(避免被洗掉)
3. **持倉階段不同**:建倉期 vs 持有期 vs 出場期,用不同紀律
4. **基本面變化**:財報、產業循環改變時,重新評估持有理由
5. **個人狀況**:資金、風險承受度改變

### 但「動態調整」不等於「隨意破壞紀律」

⚠️ 關鍵界線:
- ✅ 動態調整 = 因應市場狀態,**有理由地**修正參數
- ❌ 隨意破壞 = 因為情緒/FOMO/恐慌,**無理由地**推翻紀律

**判斷標準:這次調整,是基於市場客觀變化,還是我的情緒衝動?**
- 基於客觀變化(如趨勢轉強)→ 該調整
- 基於情緒(如手癢想買、看別人賺)→ 該守住

### 給未來 Claude 的提醒

當用戶或我自己想調整紀律時,問:
1. 市場狀態真的變了嗎?(趨勢/波動/基本面)
2. 還是只是情緒在推動?(FOMO/恐慌/手癢)
3. 這個調整有客觀依據,還是事後合理化?

**紀律是「活的框架」,不是「死的教條」——但調整必須有理由,不能是情緒的藉口。**

## 🌏 補充原則(2026-05-26):美股與台股是「獨立市場」,分開分析

### 用戶 2026-05-26 提醒

> 「美股和台股分開看和分析,兩邊是不同市場,不應該因為台股有進場美股就要停止」

### 我(Claude)犯的錯誤

當用戶問美股要不要加碼時,我用「你今天剛投 NT$222,000 到 009816(台股)」當作勸退美股加碼的理由之一。這是錯的:
- ❌ 把台股的資金部署,當成美股不能動作的理由
- ❌ 兩個獨立市場、獨立資金池、獨立帳戶,混為一談
- ❌ 台股進場 ≠ 美股要停手

### 正確原則:兩個市場完全獨立分析

| 項目 | 美股 | 台股 |
|------|------|------|
| 資金池 | 美股現金(USD)| 台股現金(NT$)|
| 標的 | NVDA/AMZN/MSFT/VOO | 009816 等 |
| 進出場判斷 | 只看美股自身訊號 | 只看台股自身訊號 |
| 紀律框架 | 美股自己的警戒/停利/停損 | 台股自己的分批/加碼 |

**一邊的動作,不該成為另一邊動作或不動作的理由。**

### 唯一的例外:總體資產配置層級

兩市場「分開分析」是對的,但有一個合理的連結點——**總資產風險配置**:
- 若用戶問「我整體資產該怎麼配」→ 可跨市場討論比例
- 但「美股某標的要不要加碼」→ 只看美股自身訊號和美股資金

**區別:個別進出場決策 = 分開看;總資產配置 = 可一起看。用戶問的若是前者,絕不用另一市場當理由。**

### 給未來 Claude 的提醒

分析某一市場的進出場時:
1. ✅ 只看該市場自身的價格、訊號、紀律、該市場的現金
2. ❌ 不要用「另一個市場剛進場/剛部署資金」當理由
3. ❌ 不要假設兩邊資金共用(除非用戶明說要跨市場調度)
4. ✅ 美股看美股的 NVDA 警戒線、美股現金;台股看台股的 009816 回檔、台股現金

## 📈 補充原則(2026-05-28):分析個股必看「股價走勢/位階」,不只看當下價

### 用戶 2026-05-28 提醒

> 「未來研判記得要看一下股價的走勢——MSFT 已經在 41X-42X 左右盤整很久,當有利多和動能時,應該要積極一點確認是否要加碼」

### Claude 的盲點

分析 MSFT 加碼時,只看「現價 vs 成本」「距警戒線多遠」「漲跌 %」等**點狀資訊**,沒看歷史走勢。漏掉了「久盤後突破」這個關鍵技術意義——這跟一般上漲完全不同,動能往往更強。

### 正確分析應該包含的「位階/走勢」維度

| 維度 | 觀察什麼 | 為什麼重要 |
|------|---------|----------|
| **長期區間** | 過去 3-6 個月在什麼價位區間 | 看是否「久盤」 |
| **盤整時間** | 在當前價位卡了多久 | 越久能量越大 |
| **突破訊號** | 是否突破近期盤整高點 | 突破 = 動能釋放起點 |
| **量價配合** | 突破時量能是否放大 | 沒量的突破常假突破 |
| **52 週位階** | 現價在 52 週高低點哪裡 | 判斷是高檔/中段/低檔 |
| **均線排列** | 多頭排列、糾結、空頭 | 趨勢方向 |

### 「久盤突破 + 利多」= 積極加碼訊號

| 情境 | 加碼訊號強度 |
|------|------------|
| 一般上漲(沒盤整背景)| 🟡 普通,看其他條件 |
| **久盤後 + 利多 + 突破盤整高** | 🟢 **強訊號,該積極加碼** |
| 已大漲一段再追 | 🔴 追高,風險高 |
| 反彈但仍在下降趨勢 | 🔴 反彈高點,別追 |

### 給未來 Claude 的提醒

分析個股加碼/進場時,**除了即時價、漲跌幅、警戒緩衝**,還必須查:

1. ✅ 過去 3-6 個月的「盤整區間」(如 MSFT $41X-$42X)
2. ✅ 在此區間卡了多久(越久越值得注意)
3. ✅ 突破訊號是否確立(收盤站上 + 量能)
4. ✅ 52 週位階(高檔 / 中段 / 低檔)
5. ✅ 均線排列方向

**「久盤後 + 利多 + 突破」是值得積極加碼的訊號,不能用『沒跌深所以不加』這種單一標準排除。**

### 工具上的修正

每次分析個股,應該主動:
- web_search 查「[標的] 近期走勢 / 盤整 / 突破」
- 或請用戶提供日K圖截圖(像 5/24 看 009816 那次)
- 用 Yahoo Finance / TradingView 查歷史價格

不能只看單點即時價就下判斷。
