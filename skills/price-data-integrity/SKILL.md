# 股價資料完整性 SKILL（最高優先級）

## 🚨 為什麼建立這個 SKILL？

### 用戶 2026-05-21 三次反饋

> **錯誤 1（TSM）**：「TSM 現在是 400 ~你哪來的 235 價格」
>
> **錯誤 2（信昌電/凱美）**：「就說你的價格都是錯的，為什麼重複出錯」
>
> **錯誤 3（規則確立）**：「每次分析台股和美股應該都要自行先抓取最新價格，不應該每次都用記憶價格」

### Claude 反覆出錯的災難性實例

| 標的 | Claude 用記憶 | 真實價 | 誤差 | 後果 |
|------|------------|--------|------|------|
| TSM ADR | $235 | **$400** | -41% | 進場價完全錯 |
| 信昌電 6173 | $83 | **$160.5** | -48% | 限價單永不成交 |
| 凱美 2375 | $88 | **$111.5** (+9.85%) | -21% | 已飆漲還推進場 |

### 為什麼會反覆出錯？

| 根因 | 後果 |
|------|------|
| ❌ 偷懶用 user memories 裡的舊資料 | 過時 |
| ❌ 用「估計值」當「事實」 | 不準 |
| ❌ 沒落實 web_search 查證 | 偷懶 |
| ❌ 限價單錯誤計算 | 用戶下不到單 |

## 🎯 強制執行規則（不允許違反）

### 🔴 規則 1：**禁止使用記憶股價**

| 場景 | 強制動作 |
|------|--------|
| 用戶問「現在 X 股價多少」 | ✅ 必先 web_search |
| 推薦進場新標的 | ✅ 必先確認當日收盤價 |
| 設計限價單 | ✅ 必先確認最新報價 |
| 計算「拉回 X%」 | ✅ 必先用真實基準（昨收）|
| 分析全市場掃描 | ✅ 必先抓所有候選標的價格 |

**違反後果**：限價單設錯 → 用戶損失機會 / 永不成交

### 🟢 規則 2：**資料優先順序（由高到低）**

```
最可信：
1. ⭐⭐⭐⭐⭐ 用戶提供的券商截圖（即時）
2. ⭐⭐⭐⭐⭐ Yahoo 股市 / Goodinfo / 玩股網（當日盤後）
3. ⭐⭐⭐⭐ web_search 結果（≤ 1 天）
4. ⭐⭐⭐ 新聞反推（如「漲 50 元至 $2,240」反推昨收）

不可信：
5. ⛔ user memories 裡的價格（可能過時）
6. ⛔ Claude 自己「估計」的價格
7. ⛔ 上一次對話的價格（時間已過）
```

### 🟡 規則 3：**美股 vs 台股的差異處理**

| 市場 | 處理方式 |
|------|--------|
| **美股** | 用戶通常會主動提供截圖（被動接收）|
| **美股**（無截圖時）| web_search「[ticker] stock price」確認 |
| **台股** | **必須主動 web_search**（用戶不會每次提供）|
| **台股 ETF/個股** | Yahoo 股市 + Goodinfo + 玩股網交叉驗證 |

### 🔵 規則 4：**台股查證的最佳查詢字串**

```
✅ 推薦查詢：
- "[股名] [股號] [月/日] 收盤"
  例：「台積電 2330 5月20日 收盤」
- "[股號] 股價 [日期]"
  例：「6173 股價 5/19」
- "[股號] 走勢"
  例：「2375 走勢」（會抓到 Yahoo 即時報價）

✅ 信任來源（cnyes/yahoo/goodinfo/wantgoo/winvest）：
- tw.stock.yahoo.com（Yahoo 股市）
- goodinfo.tw（Goodinfo 台灣股市資訊網）
- wantgoo.com（玩股網）
- cnyes.com（鉅亨網）
- statementdog.com（財報狗）

❌ 不可靠來源：
- pchome.megatime.com.tw（時間戳常常過舊）
- 沒有明確時間戳的網頁
```

## 📋 強制執行工作流程

### Step 1：判斷是否需要查股價

```
是否需要查股價？
├─ 是否要推薦進場？ → 查
├─ 是否要設限價單？ → 查
├─ 是否要計算損益？ → 查
├─ 是否要比較標的？ → 查
└─ 都不是？ → 不需要查
```

### Step 2：執行 web_search

```
For 台股：
├─ 主要查詢：「[股名] [股號] [日期] 收盤」
├─ 備援查詢：「[股號] 走勢」
└─ 交叉驗證：至少 2 個來源確認

For 美股：
├─ 用戶有提供截圖？→ 直接用
├─ 沒提供？→ web_search「[ticker] stock price today」
└─ 交叉驗證：Yahoo Finance + CNBC + MarketWatch
```

### Step 3：標註資料來源 + 時間戳

每次給股價時必須標註：

```
✅ 正確示範：
「台積電 2330：$2,250（Yahoo 股市 5/20 收盤）」
「NVDA：$220.61（用戶券商截圖 5/19 22:00）」

❌ 錯誤示範：
「台積電大約 $2,200 區」
「信昌電 ~$80」
```

### Step 4：拒絕推測

```
若 web_search 仍無明確結果：
✅ 應該說：「我查了無明確 5/20 收盤資料，能否請你提供？」
❌ 不該說：「估計約 $80 區」
```

## 🚨 紀律提醒（永久執行）

### 一定要做

- ✅ **每次推薦標的前必先 web_search**
- ✅ **每次設限價單前必先確認當日股價**
- ✅ **每次計算「拉回 X%」必先確認昨收**
- ✅ **用戶提供截圖時優先使用**
- ✅ **不確定 → 直接問用戶**

### 絕對不能做

- ❌ 用 user memories 裡的股價（可能過時/減資/分割）
- ❌ 用「估計值」做建議
- ❌ 用「大約」「~」開頭的數字當事實
- ❌ 上一次對話的股價（除非剛剛確認過）
- ❌ 美股報價忘記查（雖然用戶常提供，但無提供時也要查）

## 📊 真實案例對照

### 案例 1：信昌電 6173

```
❌ Claude 錯誤行為：
- 用 user memories 裡的「$83.2」（5/28 舊資料 + 減資前）
- 直接推薦限價 $83
- 沒查證

✅ 正確行為應該是：
1. 主動 web_search「信昌電 6173 股價」
2. 找到 Yahoo 股市顯示 5/19 收 $160.5
3. 注意公司公告「決議辦理現金減資」（4/29）
4. 限價應在 ≤ $160 才合理
5. 提供 1 張 = NT$160,000（不是 NT$83,000）
```

### 案例 2：凱美 2375

```
❌ Claude 錯誤行為：
- 估計 5/20 收 $88
- 推薦限價 $90
- 沒查 5/20 盤中已 +9.85% 至 $111.5

✅ 正確行為應該是：
1. web_search「凱美 2375 5月20日 股價」
2. 發現 5/20 盤中已 +9.85% 至 $111.5
3. 標記為「已飆漲不該追」
4. 移出推薦清單
```

### 案例 3：TSM ADR

```
❌ Claude 錯誤行為：
- 用記憶中的 $235（老資料）
- 推薦進場
- 用戶指出實際 $400

✅ 正確行為應該是：
1. web_search「TSM stock price」
2. 確認 $400 並算溢價 vs 台積電 2330
3. 發現 +16% 溢價
4. 建議改買台積電 2330 而非 TSM
```
