## 📋 具體操作建議

### 本週動作：**持有不變（9 檔）**

理由總結：
1. 所有持倉仍正報酬，無任何一檔觸發出場條件
2. 估值反而從高位大幅壓縮，向下空間有限
3. 軟體股逆勢強驗證機構仍在介入
4. 本週三大事件都是「可能加分」的機會，不是「必然扣分」的風險

### 預備條件式動作：

**條件 A（若 4/22 停火破局 + 油價破 $100 且持續 2 週）**：
- 賣 00679B 全部 3 張（論點正被侵蝕）
- 釋出 ~$250 + 原有 $66 = ~$316 現金
- 準備 MSFT 若跌破 $390 時加 1 股（~$385-390）

**條件 B（若 AMZN 財報 AWS 增速跌破 22%）**：
- 重新評估 AMZN 論點
- 不立即行動，但加強觀察下一季

**條件 C（若 MSFT 財報 Azure 跌破 35%）**：
- Azure 39% → 35% 是警戒
- Azure < 30% 且連續 2 季才考慮賣出
- 單次不達預期不是賣出訊號
